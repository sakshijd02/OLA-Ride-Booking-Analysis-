# 🚖 OLA Ride Booking Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing OLA ride booking data to understand booking performance, revenue generation, vehicle preferences, cancellation patterns, and customer satisfaction.

Using Excel, SQL, Power BI, and Power Query, the project transforms raw booking data into meaningful business insights through interactive dashboards.

## 🎯 Project Objectives
- Analyze overall ride booking performance.
- Identify the most frequently booked vehicle types.
- Analyze revenue generation and contribution by vehicle type.
- Understand customer and driver cancellation patterns.
- Evaluate customer and driver ratings.
- Build an interactive Power BI dashboard for business reporting.

## 🛠️ Tools & Technologies
- **Microsoft Excel:** Data cleaning and preparation.
- **SQL:** Data querying and analysis.
- **Power BI:** Interactive dashboard creation and reporting.
- **Power Query:** Data transformation and preparation.

## 📂 Dataset Information
The dataset contains OLA ride booking information, including:

- Booking ID
- Booking Date and Time
- Booking Status
- Customer ID
- Vehicle Type
- Pickup and Drop Location
- Booking Value
- Payment Method
- Ride Distance
- Driver Ratings
- Customer Ratings
- Cancellation Details
- Incomplete Ride Reasons

The project presentation describes the dataset as approximately 100,000 records.
